# ריכוז

פומודורו אישי בעברית. הטיימר רץ בדפדפן, הנתונים נשמרים רק על המכשיר, ואפשר להוסיף אותו למסך הבית באייפון.

## הרצה מקומית

```bash
npm install
npm run dev
```

האפליקציה עולה בכתובת [http://127.0.0.1:43123](http://127.0.0.1:43123).

כדי לראות את האתר הסטטי כמו בפריסה:

```bash
npm run build
npm start
```

`npm start` מגיש את התיקייה `out` באותה כתובת.

```bash
npm test
npm run lint
```

## הוספה לאייפון

1. פותחים את האתר בספארי.
2. לוחצים על כפתור השיתוף.
3. בוחרים «הוסף למסך הבית».
4. לוחצים «הוסף».

האייקון «ריכוז» נפתח במסך מלא, בלי סרגל של הדפדפן. אין חשבון ואין שרת: ההיסטוריה, היעד וההגדרות נשמרים ב־localStorage של הדפדפן.

התראה בסיום סשן באייפון זמינה אחרי ההוספה למסך הבית. אם המסך נעול, מערכת ההפעלה עלולה להשהות את העמוד, ולכן ההתראה יכולה להופיע רק כשחוזרים. הזמן עצמו מחושב לפי שעון אמיתי, וסשן שרץ מושלם גם אם חוזרים אליו אחר כך. סשנים שלא באמת רצו לא נספרים.

## מה יש באפליקציה

- מיקוד, הפסקה קצרה והפסקה ארוכה, עם סבב של ארבעה סשנים כברירת מחדל
- משכי זמן, יעד יומי, שם לתצוגה והפעלה אוטומטית
- מעקב יומי, רצף ימים ושבוע אחרון
- צליל, רטט במכשירים שתומכים, והתראה בסיום
- שמירת המסך דלוק בזמן שסשן רץ והאפליקציה פתוחה

## פריסה ב־Cloudflare Pages

האתר סטטי. `npm run build` כותב את כל הקבצים לתיקייה `out`, ומחברים את מאגר GitHub ל־Cloudflare Pages.

בהגדרות הבנייה:

- Framework preset: None, או Next.js (Static HTML Export)
- Build command: `npm run build`
- Build output directory: `out`
- משתנה סביבה `NODE_VERSION`: `22.23.3`

זו הגרסה שבה נבדק הבילד. אותו מספר נמצא בקובץ `.node-version` בשורש, ו־Pages משתמש בו גם אם לא מגדירים את המשתנה ידנית. Next.js 16 צריך Node `20.9.0` ומעלה.
