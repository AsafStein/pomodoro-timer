# ריכוז

פומודורו אישי בעברית. הטיימר רץ בדפדפן, הנתונים נשמרים רק על המכשיר, ואפשר להוסיף אותו למסך הבית באייפון.

## הרצה מקומית

```bash
npm install
npm run dev
```

האפליקציה עולה בכתובת [http://127.0.0.1:43123](http://127.0.0.1:43123).

כדי לראות את האתר הסטטי כמו בפריסה:

```bash
npm run build
npm start
```

`npm start` מגיש את התיקייה `out` באותה כתובת.

```bash
npm test
npm run lint
```

## הוספה לאייפון

1. פותחים את האתר בספארי.
2. לוחצים על כפתור השיתוף.
3. בוחרים «הוסף למסך הבית».
4. לוחצים «הוסף».

האייקון «ריכוז» נפתח במסך מלא, בלי סרגל של הדפדפן. אין חשבון ואין שרת: ההיסטוריה, היעד וההגדרות נשמרים ב־localStorage של הדפדפן.

התראה בסיום סשן באייפון זמינה אחרי ההוספה למסך הבית. אם המסך נעול, מערכת ההפעלה עלולה להשהות את העמוד, ולכן ההתראה יכולה להופיע רק כשחוזרים. הזמן עצמו מחושב לפי שעון אמיתי, וסשן שרץ מושלם גם אם חוזרים אליו אחר כך. סשנים שלא באמת רצו לא נספרים.

## מה יש באפליקציה

- מיקוד, הפסקה קצרה והפסקה ארוכה, עם סבב של ארבעה סשנים כברירת מחדל
- משימות: יצירה, שינוי שם, ארכיון ומחיקה, ושיוך סשן הריכוז הנוכחי
- שמירת פומודורו שהושלם, וגם זמן מיקוד חלקי אם עוצרים באמצע
- דוחות ליום, לשבוע (החל מיום ראשון) ולחודש, עם פירוט לפי משימה
- משכי זמן, יעד יומי, שם לתצוגה והפעלה אוטומטית
- מעקב יומי, רצף ימים ושבעה ימים אחרונים
- צליל, רטט במכשירים שתומכים, והתראה בסיום
- שמירת המסך דלוק בזמן שסשן רץ והאפליקציה פתוחה

## פריסה ב־Cloudflare Workers

האתר סטטי. `npm run build` כותב את כל הקבצים לתיקייה `out`, ו־Worker מגיש רק את הקבצים האלה, בלי קוד שרת. שם הפרויקט ב־`wrangler.jsonc` הוא `pomodoro-timer`. נתיב שלא קיים מקבל את `404.html`.

ב־Workers Builds, תחת Settings > Build:

- Root directory: `/`
- Build command: `npm run build`
- Deploy command: `npx wrangler deploy`
- Build variable `NODE_VERSION`: `22.23.3`

זו הגרסה שבה נבדק הבילד. אותו מספר נמצא בקובץ `.node-version` בשורש. Next.js 16 צריך Node `20.9.0` ומעלה.

`public/_headers` מועתק ל־`out` בזמן הבילד, ו־Workers מפעיל אותו על הנכסים הסטטיים.

אם יומן הפריסה אומר שלחשבון אין תת־דומיין workers.dev, רושמים אחד בלוח הבקרה תחת Workers & Pages (הגדרת תת־הדומיין workers.dev ברמת החשבון) ומנסים שוב את הבילד.
